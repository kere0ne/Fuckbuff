# Fuckbuff

**The free coding agent.** No subscription. No configuration. Start in seconds.

An AI coding agent that runs in your terminal — describe what you want, and Fuckbuff edits your code.

## Install

```bash
npm install -g fuckbuff
```

## Usage

```bash
cd ~/my-project
fuckbuff
```

## Project Structure

```
fuckbuff/
├── cli/       # CLI build & npm release files
└── web/       # Fuckbuff website
```

## Building from Source

```bash
# From the repo root
bun fuckbuff/cli/build.ts 1.0.0
```
